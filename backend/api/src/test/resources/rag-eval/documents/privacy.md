# 가람상사 개인정보 처리 지침

## 제1조 (목적)
이 지침은 고객과 임직원의 개인정보를 모으고, 쓰고, 지우는 기준을 정한다. 일반적인 보안 수칙과 보안 사고 신고는 정보 보안 지침을 따른다.

## 제2조 (최소 수집)
업무에 꼭 필요한 개인정보만 모으고, 모을 때는 목적과 보관 기간을 알리고 동의를 받는다. 주민등록번호는 법에서 허용한 경우에만 모은다.

## 제3조 (처리 담당자)
개인정보를 다루는 직원은 개인정보 처리 담당자로 지정되어야 하며, 해마다 개인정보 보호 교육을 받는다. 담당자 목록은 개인정보보호팀이 관리한다.

## 제4조 (접근 권한)
개인정보가 든 시스템의 접근 권한은 업무에 필요한 만큼만 주고, 부서를 옮기면 바로 회수한다. 접근 기록은 2년 동안 보관한다.

## 제5조 (암호화)
주민등록번호, 계좌번호, 비밀번호는 저장할 때 반드시 암호화한다. 개인정보가 든 파일을 메일로 보낼 때도 파일에 암호를 건다.

## 제6조 (외부 제공)
개인정보를 다른 회사에 주려면 개인정보보호팀의 검토를 받고, 받는 회사와 개인정보 처리 위탁 계약을 맺는다.

## 제7조 (파기)
보관 기간이 끝난 개인정보는 5일 안에 지운다. 종이 문서는 문서 세단기로, 파일은 복구할 수 없게 지운다.

## 제8조 (열람·정정 요청)
고객이 자신의 개인정보 열람이나 정정을 요청하면 10일 안에 처리하고 결과를 알린다. 처리할 수 없으면 그 사유를 알린다.

## 제9조 (유출 대응)
개인정보 유출을 알게 되면 즉시 개인정보보호팀에 알리고, 72시간 안에 피해자에게 통지한다. 1천 명 이상이 유출되면 관계 기관에도 신고한다.

## 제10조 (점검)
개인정보보호팀은 반기마다 부서별 개인정보 처리 실태를 점검하고, 위반한 직원에게는 징계를 요청할 수 있다.
