# 가람상사 정보자산 관리 지침

## 제1조 (목적)
이 지침은 회사의 소프트웨어, 클라우드 계정, 데이터 같은 정보자산을 등록하고 관리하는 방법을 정한다. 노트북·모니터 같은 실물 장비는 장비 관리 규정을, 비밀번호와 보안 사고는 정보 보안 지침을 따른다.

## 제2조 (자산 대장)
정보자산팀은 회사가 쓰는 모든 소프트웨어 라이선스와 클라우드 서비스를 자산 대장에 올리고 반기마다 점검한다. 대장에 없는 서비스는 업무에 쓰지 않는다.

## 제3조 (소프트웨어 구매)
업무에 필요한 소프트웨어는 옹기마루에서 구매 요청을 하고 정보자산팀의 검토를 받는다. 무료 소프트웨어라도 상업적 사용이 허용되는지 확인한 뒤 설치한다.

## 제4조 (라이선스 회수)
퇴사하거나 부서를 옮긴 직원의 라이선스는 정보자산팀이 7일 안에 회수해 다른 직원에게 다시 배정한다. 회수하지 못한 라이선스는 다음 갱신 때 줄인다.

## 제5조 (클라우드 계정)
사내 클라우드 계정은 개인 메일이 아니라 회사 메일로만 만든다. 관리자 권한은 두 명 이상에게 나눠 주고, 분기마다 접근 기록을 검토한다.

## 제6조 (데이터 등급)
회사 데이터는 공개, 내부, 대외비, 극비의 네 등급으로 나눈다. 대외비 이상 자료는 사내 저장소 "곳간"에만 두고 외부 공유 링크를 만들지 않는다.

## 제7조 (보존 기간)
계약서와 회계 자료는 10년, 인사 기록은 퇴사 후 3년, 일반 업무 메일은 5년 동안 보존한다. 보존 기간이 지난 자료는 정보자산팀이 분기마다 지운다.

## 제8조 (백업)
곳간의 자료는 매일 밤 다른 지역의 데이터센터로 백업하고, 백업본은 30일 동안 보관한다. 백업 복구 훈련은 반기마다 한다.

## 제9조 (폐기)
저장 매체를 버릴 때는 정보자산팀이 데이터를 완전히 지운 뒤 폐기 확인서를 남긴다. 직원이 직접 버리거나 중고로 팔지 않는다.

## 제10조 (점검)
정보자산팀은 해마다 정보자산 관리 실태를 점검하고 결과를 경영진에게 보고한다. 지적 사항은 3개월 안에 고친다.
